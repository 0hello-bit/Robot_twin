# Claude Code 持久上下文入口设计

## 目标

让每次全新的 Claude Code 会话在不扫描全仓库的情况下，快速理解 Robot Twin AI 的长期目标、当前阶段、安全边界和唯一当前任务，降低重复阅读耗时与额度消耗。

## 文件分工

1. 仓库根目录 `CLAUDE.md`
   - Claude Code 的自动入口。
   - 只包含项目定位、权威文档入口、强制安全边界和最小工作流程。
   - 保持短小，不复制完整计划书。

2. `docs/agent-context/CURRENT_STATUS.md`
   - 只记录最新的已验证事实、尚未验证项、当前阻塞和下一步。
   - 每次完成独立验收后更新，旧事实不得未经证据覆盖。

3. `docs/agent-context/handoffs/<task>.md`
   - 一项任务一个短交接文件。
   - 固定包含：范围、输入、允许修改、禁止动作、验收命令、交付格式。
   - 执行代理只读当前 handoff 指向的必要文件，不自行全仓库摸索。

## Claude Code 启动契约

每次只发送一句入口提示：

> 先完整读取仓库根 `CLAUDE.md`，再读取本次指定 handoff；严格按范围执行，禁止扫描全仓库。完成后报告实际改动、验证结果、未验证项和下一接口。

## 当前任务

当前 handoff 将记录本轮真机结果，并只要求返工 `transport_soak.py`：

- 复现未传 `--run` 却发送 STOP、START 和 H 帧的问题。
- 修复模式判定，使真正被动模式的 TCP TX 字节数严格为 0。
- 保留 `--run` 的安全握手行为。
- 运行离线测试；不连接硬件、不烧录、不发送真实命令。

## 安全与更新规则

- “构建通过”不能替代真实硬件证据。
- 未经当次明确授权，不烧录、不 START、不控制电机。
- `CURRENT_STATUS.md` 区分已验证事实、推断和未验证项。
- 执行代理不得擅自宣布阶段或项目完成。
- 长期背景只在 `CLAUDE.md` 维护；任务细节只进 handoff，避免入口膨胀。

## 验收标准

- 新会话只读入口与一个 handoff 即可开始工作。
- 不需要重新遍历三份 PDF、完整计划书或全部历史证据。
- 被动模式回归测试证明零 TX；运行模式既有测试无回归。
- 所有路径为仓库相对路径，不写入密码、个人绝对路径或设备密钥。
