# Task 4B-2 C1 单程开放路线设计

## 已确认的用户意图

- 真实赛道只保留掩码主组件 `C1`；`C2`—`C7` 均不是赛道。
- 小车从图中“发”字所在的发车支线进入，先向上到主赛道，再向右行驶。
- 虽然 `C1` 的原始几何拓扑含环形部分和连接节点，但不存在需要车辆自主选择的语义岔路；路线顺序由发车方向唯一确定。
- 车辆绕过右侧、上侧和左侧后，从中央横线驶向终点的全黑横向标记。
- 全黑标记之后是全白区域，没有可继续跟踪的黑线。因此本路线不是闭环，终点之后不得声称“持续巡线”。

## 路线模型

路线类型为 `open_traversal_on_cyclic_mask`：底层掩码可以包含环形几何，但交付给横向误差计算和车辆任务逻辑的是一条有起点、有方向、有终点的有序开放中心线。

路线顺序以 `track_bare.png` 的 1280×720 像素坐标记录，并把下列人工锚点吸附到最近的 C1 骨架点：

1. 发车起点 `(928, 599)`
2. 发车支线与主赛道连接处 `(929, 480)`
3. 进入后向右 `(1120, 480)`
4. 右侧上行 `(1220, 160)`
5. 上侧右段 `(900, 50)`
6. 上侧左段 `(500, 50)`
7. 左侧入口 `(390, 190)`
8. 左侧外弯 `(185, 420)`
9. 左侧下弯 `(390, 690)`
10. 中央返回段 `(610, 500)`
11. 终点接近段 `(760, 480)`
12. 全黑终点标记中心 `(810, 480)`

每个锚点必须在 60 px 内吸附到 C1 骨架。输出中心线必须按上述顺序经过锚点，不允许用最短路从发车连接处直接切向终点，也不允许反向折返或跨越白区。

> 该坐标落在印刷“发”字上（纸面墨迹，非 C1 掩码），距最近 C1 骨架点 101px，

## 终点语义

本次 4B-2 只在路线元数据中记录终点行为，不修改 MCU 固件：

1. 正常巡线到达路线末端附近。
2. 四路巡线传感器稳定检测到全黑终点标记时，进入终点状态。
3. 低速直行穿过标记；PID 积分应冻结，避免积分饱和。
4. 检测到全白后制动停车，并把本轮记录为完成。
5. 全白后继续直行只能称为盲走，不能称为巡线；V1 不采用该行为。

具体的传感器去抖时间、穿越速度和安全超时属于后续控制任务，必须通过真车实验确定，不在 4B-2 中臆造固定数值。

## 数据约束

路线选择证据必须明确包含：

```json
{
  "selected_components": ["C1"],
  "route_type": "open_traversal_on_cyclic_mask",
  "start_semantics": "launch_zone_FA_enter_then_turn_right",
  "terminal_marker": "all_black",
  "after_terminal_surface": "all_white",
  "terminal_policy": "cross_marker_then_stop_on_white",
  "semantic_branches": 0,
  "closed_loop": false
}
```

原始 `route_choices.json` 是历史阻塞证据，不得删除或改写；新的用户选择和生成结果写入新的验收目录。

## 验收条件

- 仅使用 C1，且 C2—C7 不进入中心线或路线掩码。
- 路线起点靠近发车锚点，进入主赛道后的首个方向为右。
- 所有锚点按规定顺序被访问。
- 输出是一条开放有序点列，逻辑上只有一个起点和一个终点。
- 相邻点不跨白区，不存在大跳变、重复边、反向折返或未说明的分支选择。
- 终点位于全黑标记，终点之后不延伸到全白区域。
- 生成的 overlay 能让独立审核者直接看出起点、箭头方向、终点以及 C2—C7 被排除。
- 现有相机、标定、轨道地图和位姿跟踪核心测试不得回归。
- **输入完整性（独立审核返工新增）**：完整赛道俯视图的 C1 掩码不得接触任一
  图像边界。只要 C1 掩码接触任一边界即判定输入被裁切（`input_cropped=true`、
  `gates_pass=false`、状态 `BLOCKED_INPUT_CROPPED`）；起点与终点在当前设计中
  都不应位于图像边界，不设任何起终点豁免。当前 `track_bare.png` 因画面底边
  裁切（C1 掩码 167 触点、中心线 131 点压在 y=719），不可作为可验收真实地图，
  需重新采集四周留白、包含完整赛道的新俯视图。

## 范围与安全边界

- 允许：离线读取现有图片和标定文件；修改 4B-2 路线提取代码及其直接测试；生成全新证据目录。
- 禁止：连接或复位 MCU、烧录、擦除 Flash、控制电机、访问 ESP/串口/TCP、修改 Keil 工程、重新执行 4B-1 摄像头长测。
- 本阶段的软件 PASS 只证明路线提取满足上述定义，不证明真车已经跑完全程。
