# 俯拍 AprilTag 小车定位

该模块使用固定在赛道上方的普通摄像头识别小车顶部 AprilTag，计算地面
坐标 `x、z、yaw`，再发送到现有数字孪生 WebSocket 接口。定位代码与 STM32
控制代码、ESP01S 遥测和 3D 模型相互独立，以后改成 K230 时保持相同 JSON
输出即可。

## 当前摄像头选择

当前先使用 vivo 平板，不使用 iPhone 作为第一次联调设备。平板和电脑接入同一
局域网，在平板和 Windows 上启动 DroidCam，建议先设置为 1280×720、30 fps。
在 `web_showcase` 目录运行 `configure_mobile_camera.ps1`，输入 DroidCam 显示
的平板 IP。脚本会保存形如 `http://平板IP:4747/video` 的视频地址并立即探测
画面；探测成功后再做地面标定。

iPhone 也可通过 DroidCam 的 iOS 客户端接入，但 Windows 不能直接使用苹果面向
Mac 的连续互通相机功能。为减少首轮联调变量，先把 vivo 链路跑通。

## 一次性准备

1. 运行 `generate_apriltag.py`，打印生成的 `apriltag_36h11_id0.png`。
2. 打印时关闭“适应页面”。5 cm 可作为小车首轮测试尺寸，但最终能否稳定识别
   取决于摄像头高度和清晰度；预览中标签像素面积不足时需要放大。
3. 标签水平贴在小车顶部，标签图片的上边朝向车头。
4. 摄像头固定在赛道正上方，画面覆盖完整赛道，之后不要再移动支架。
5. 在地面选择一个矩形标定区域，测量 X、Z 两个方向的实际长度。

## 地面标定

运行 `web_showcase/calibrate_camera_tracking.ps1`，输入标定矩形的实际尺寸，
然后在冻结画面中依次点击：

1. 原点 `(0,0)`
2. X 轴端点
3. 对角点
4. Z 轴端点

按 `S` 保存，`R` 重新点击，空格重新截取画面，`Q` 退出。结果保存在
`tracker_config.json`。

现在也可以直接在调参网页的“现实轨道自动建图”中填写摄像头来源和标定区
实际宽高，然后点击“打开地面四点标定”。

## 现实轨道自动建图

1. 地面标定完成后，先把小车、AprilTag 和其他杂物移出画面。
2. 保证黑色轨道闭合、整圈可见，避免明显阴影和黑色地板花纹。
3. 在网页点击“扫描并应用现实轨道”。
4. 识别结果保存为 `track_map.json`，调试预览保存为
   `track_scan_preview.png`；以后打开面板会自动加载已保存轨道。
5. 把带 AprilTag 的小车放回轨道。视觉定位输出会和轨道共用同一套米制坐标，
   不再依赖首次位置的人工对齐。

轨道扫描识别的是“闭合黑色轨道带”，本身不需要 AprilTag；AprilTag 用于扫描
完成后定位运动中的小车。若轨道不闭合、被小车遮挡或与地板黑色区域连成一片，
系统会拒绝结果而不是猜测。电脑 USB 摄像头可能无法同时被定位预览和扫描程序
占用，遇到“摄像头读取失败”时先关闭定位预览，再重新扫描。

## 启动

1. 先打开原来的 `STM32小车调参面板` 桌面快捷方式。
2. 完成一次标定后，原快捷方式会自动启动视觉定位；也可以手动运行
   `web_showcase/launch_camera_tracking.ps1`。
3. 摄像头预览中显示标签轮廓和 `x、z、yaw`；按 `Q` 退出。
4. 调参面板中的 `Pose input` 应显示 `online`，蓝线为视觉实测轨迹。

## 配置说明

- `tag.id`：车顶标签编号，默认 `0`。
- `tag.front_edge`：标签哪条边朝车头，默认 `top`。
- `tag.car_center_offset_forward/right`：标签中心相对车体中心的偏移。
- `tag.minimum_pixel_area`：标签过小或模糊时拒绝发送。
- `filter.max_jump`：单帧允许的最大位置跳变，单位与标定一致。
- `output.websocket_url`：默认 `ws://127.0.0.1:8787/live`。
- `output.auto_start_with_panel`：完成标定后是否随原调参面板自动启动。

摄像头或标签被遮挡超过 750 ms 后，3D 面板会停止使用外部位姿并退回
PWM + MPU6050 估算。视觉恢复后重新使用实时位置。

质量低于 `0.7` 的位姿不会强制修正3D小车。当前方法仍是地面单应矩阵，车顶
标签高度会产生视差；在完成摄像头内参、标签高度和实测网格误差验证前，不应
把它称为高精度绝对定位。

## 后续切换 K230

K230 版本位于 `k230/`。它在板端识别 AprilTag，并通过 UDP 8788 直接发送
`x、z、yaw`；电脑端调参面板的桥接程序已经能够接收，无需改浏览器。K230 的
具体联网初始化取决于之后购买的板型，拿到实物后只需补联网方式和电脑 IP。
